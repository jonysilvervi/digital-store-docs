# Серая схема: страница товара ChatGPT

Ветка `gh-pages` содержит только демонстрационный прототип. Главный бриф и документы — в ветке `main`, эта ветка их не меняет.

- Просмотр: https://jonysilvervi.github.io/digital-store-docs/
- Исходник: `index.html` в этой ветке — один самостоятельный файл без сборки и зависимостей (кроме шрифта Google Fonts; без него страница работает с системным шрифтом).
- Автор схемы: Claude, проектировщик сайта. Дата: 20.10.2026.

## Статус

- Это **серая схема структуры**, не дизайн. Цвета, шрифты и графику задаст GPT Design.
- Основа подачи («компактная главная, понятные предложения внутри тарифа») принята пользователем как направление. **Конкретный интерфейс не согласован.**
- Главная в этой итерации не переделывалась.
- Все предложения, цены, лимиты количества и тексты условий — **демо**. Названия тарифов Go, Plus, Pro, Business сверены с https://chatgpt.com/pricing/ на 20.10.2026; официальных цен на странице в тексте не было, официальные цены не используются.

## Как устроена страница

Сверху вниз:

1. **Шапка магазина:** логотип, поиск, кабинет, корзина со счётчиком, меню.
2. **Строка «Демо-прототип»** — одна строка под шапкой, прокручивается вместе со страницей. Кнопка «Состояния» открывает лист с переключением демо-состояний. Служебной панели над сайтом нет.
3. Путь «Каталог › ChatGPT», место под изображение, название, одна строка описания.
4. **Тариф** — сегменты Go / Plus / Pro / Business, без цен. Ссылка «Сравнить тарифы» открывает лист.
5. **Предложение** — все предложения выбранного тарифа строками: название, цена за выбранный срок, один короткий факт. Количество строк не ограничено: показываются все предложения тарифа. Недоступное — бледное, «Нет в наличии», ссылка «Сообщить о поступлении».
6. **Срок** — сегменты из сроков этого тарифа. Срок, которого нет у выбранного предложения, неактивен.
7. **После выбора предложения** появляется один блок:
   - количество — только если предложение разрешает больше одной штуки;
   - «Перед покупкой» — существенные ограничения и что понадобится от покупателя, обычным языком;
   - ссылка «Все условия предложения» — лист с полными условиями.
8. **Вопросы** — три свёрнутых пункта.
9. **Закреплённая панель покупки** внизу.

## Решения и почему

**Предложения внутри тарифа.** Покупатель, который знает нужный тариф, выбирает его в одно нажатие. Внутри видит готовые названия («На ваш аккаунт», «Отдельный аккаунт», «Место в общем аккаунте», «Место в рабочем пространстве») вместо технических ярлыков. Длинной ленты нет, потому что показываются предложения одного тарифа, а не все сразу. Предложений в тарифе может быть сколько угодно.

**Тариф и срок выбраны заранее только для прототипа.** Plus и 1 месяц выбраны, чтобы сразу была видна цена в строках. Это не рекомендация и не данные о популярности. Предложение заранее не выбирается.

**Если у предложения нет выбранного срока**, в строке показана цена за доступный срок («6,90 € на 1 мес»). При выборе срок переключается, и под сроками появляется явная пометка «Срок изменён…». Молча ничего не меняется.

**Цена показывается в двух местах без дублирования крупных блоков:** в строке предложения (цена за единицу на выбранный срок) и в панели (итог с учётом количества и «≈ €/мес» для сроков больше месяца). Отдельного крупного блока цены в содержимом нет.

**Зачем закреплённая панель.** На телефоне после выбора предложения, условий и количества кнопка покупки уходит за нижний край экрана. Панель держит итог и действия под пальцем. Как она не мешает:
- одна строка высотой около 66 px, без дублирования условий;
- внизу страницы есть отступ под панель, поэтому содержимое не перекрывается;
- до выбора кнопки неактивны, итог показан как «от X».

**Две покупки с иерархией.** «Купить сейчас» — основная широкая кнопка. «В корзину» — вторичная квадратная кнопка со значком корзины и подписью для экранных читалок. После добавления в корзину растёт счётчик в шапке. Лист корзины не используется как замена прямой покупке.

**Ограничения видны до покупки.** Блок «Перед покупкой» показывает 1–2 существенных ограничения выбранного предложения. Подробности — в «Всех условиях». Галочка при оформлении, если будет, — дополнение, а не замена.

**Требования обычным языком.** Внутри данных у каждого требования есть область: заказ, позиция или единица. Покупатель видит готовую фразу, например:
- «Понадобится почта вашего аккаунта ChatGPT — для каждой из 2 активаций.»
- «Понадобится почта участника — для каждого из 3 мест; название команды.»
- «От вас нужна только почта для получения заказа.»

## Неизвестное и оговорки

- Тексты ограничений — черновик. Формулировка про общий аккаунт («ваши чаты могут видеть другие участники») — осторожное предупреждение, а не подтверждённое описание. Утвердить после проверки реальных условий.
- Требование «аккаунт без действующей платной подписки» — демо-пример, не проверенное условие.
- Описания тарифов в листе «Сравнить тарифы» не заполнены: только из официальных данных OpenAI после проверки.
- Выдача, сроки выдачи, гарантия, замена и возврат — не утверждены, в листе условий стоят заготовки.
- Изображение товара — заглушка. Использование логотипа OpenAI нужно сверить с их правилами бренда; безопаснее собственная иллюстрация.
- Корзина, оформление, страница заказа и кабинет — следующие схемы. Кнопки «Купить сейчас» и «В корзину» здесь показывают только уведомление.

## Что нужно от GPT Design для этой страницы

- Сегменты (тариф, срок): обычный, выбран, недоступен.
- Строка предложения: обычная, выбрана, нет в наличии.
- Блок «Перед покупкой» с количеством.
- Закреплённая панель: до выбора и после.
- Листы поверх страницы: сравнение тарифов, условия, демо-состояния.
- Изображение товара и строка демо-пометки.
