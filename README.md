# Digital Store Docs

Рабочая документация будущего магазина цифровых товаров. ChatGPT — первый сервис в ассортименте; бренд и окончательная структура магазина ещё не выбраны.

## Главный бриф

[Открыть PROJECT_BRIEF.md](./PROJECT_BRIEF.md)

[Прямой текст для ИИ](https://raw.githubusercontent.com/jonysilvervi/digital-store-docs/main/PROJECT_BRIEF.md)

Бриф содержит контекст, принятые решения, ограничения, открытые вопросы, правила взаимодействия и текущий этап. Это основной документ для переноса контекста между чатами.

## Начало нового чата

Передайте чату прямую ссылку на бриф и попросите:

«Прочитай главный бриф полностью по ссылке выше. Назови версию и кратко восстанови: цель проекта, согласованные решения, ограничения, открытые вопросы и текущий следующий шаг. Не начинай реализацию. Если документ недоступен или прочитан не полностью, сообщи прямо».

После проверки контекста задайте конкретную задачу этого чата. Новые чаты не получают изменения автоматически: после обновления брифа попросите перечитать ссылку.

## Обновления

Существенные решения вносятся в PROJECT_BRIEF.md с обновлением версии и истории изменений. Не публикуйте здесь секреты и закрытые данные. Репозиторий содержит документацию; код магазина может храниться отдельно.
