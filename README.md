# Digital Store Docs

Рабочая документация будущего магазина цифровых товаров. ChatGPT — первый сервис в ассортименте; бренд и окончательная структура магазина ещё не выбраны.

## Главный бриф

[Открыть PROJECT_BRIEF.md](./PROJECT_BRIEF.md)

[Прямой текст для ИИ](https://raw.githubusercontent.com/jonysilvervi/digital-store-docs/main/PROJECT_BRIEF.md)

Бриф содержит контекст, принятые решения, ограничения, открытые вопросы, правила взаимодействия и текущий этап. Это основной документ для переноса контекста между чатами.

## Начало нового чата

1. Откройте [главный бриф](./PROJECT_BRIEF.md), раздел 12.
2. Выберите готовый стартовый запрос: GPT — стратегия, GPT — дизайн, Claude — проектирование и реализация.
3. Передайте соответствующий запрос в новый чат. Он содержит ссылку, роль, текущую задачу и границы.
4. Если тестовый чат уже прочитал старую версию, попросите перечитать актуальный бриф и назначьте нужную роль. Создавать замену только ради обновления не нужно.

Перенос ранней редакции брифа в новый GPT-чат уже проверен пользователем: получен корректный пересказ основной картины. Актуальная версия — 0.1. Номер меняется только по решению пользователя; текущие правки видны в истории GitHub и журнале брифа. Пересказ не гарантирует безошибочного выполнения будущих задач.

Чаты не синхронизируются автоматически. После значимых изменений обновите бриф и попросите другие рабочие чаты перечитать его. В случае недоступности ссылки чат должен сообщить об этом прямо.

## Обновления

Существенные решения вносятся в PROJECT_BRIEF.md с обновлением журнала изменений; версия остаётся 0.1 до решения пользователя. Не публикуйте здесь секреты и закрытые данные. Репозиторий содержит документацию; код магазина может храниться отдельно.
