    Вопросы

    Как проходит покупка?

    Выбираете предложение, оплачиваете, получаете доступ по ссылке из письма. Подробный порядок выдачи будет в условиях предложения.

    Нужна ли регистрация?

    Нет. Для заказа нужна только почта. Кабинет с историей заказов и продлением — по желанию, вход по коду на почту.

    Что если доступ перестанет работать?

    Порядок замены и возврата будет указан в условиях каждого предложения.
